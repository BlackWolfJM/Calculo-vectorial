# 01 — Cónicas en coordenadas cartesianas

En este tema se estudian las curvas obtenidas al intersectar un plano con un cono doble y sus ecuaciones en coordenadas cartesianas.

## Subtemas con material disponible

- [Elipse](./Elipse/): teoría, procedimiento de análisis y notebook interactivo.
- [Hipérbola](./Hipérbola/): teoría básica y notebook de visualización.

## Forma de trabajo

1. Identificar la cónica y llevar su ecuación a forma estándar.
2. Reconocer centro, orientación y parámetros.
3. Calcular sus elementos geométricos.
4. Dibujar un bosquejo manual.
5. Verificar la gráfica con Python cuando sea útil.

> La teoría se conserva en Markdown y la experimentación gráfica en notebooks de Colab.
