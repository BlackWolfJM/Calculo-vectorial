# Hipérbola

Una **hipérbola** es el conjunto de puntos del plano para los cuales el valor absoluto de la diferencia de distancias a dos focos es constante.

## Formas estándar

### Eje transversal horizontal

$$\frac{(x-h)^2}{a^2}-\frac{(y-k)^2}{b^2}=1$$

### Eje transversal vertical

$$\frac{(y-k)^2}{a^2}-\frac{(x-h)^2}{b^2}=1$$

En ambos casos:

$$c^2=a^2+b^2, \qquad e=\frac{c}{a}>1$$

## Elementos clave

- Centro: $(h,k)$.
- Vértices: a distancia $a$ del centro sobre el eje transversal.
- Focos: a distancia $c$ del centro.
- Asíntotas horizontales: $y-k=\pm\frac{b}{a}(x-h)$.
- Asíntotas verticales: $y-k=\pm\frac{a}{b}(x-h)$.
