# 25. Definición formal ε-δ para funciones vectoriales

## Subtemas

- Definición:
  $$
  0<|t-a|<\delta\ \Longrightarrow\ \|\mathbf r(t)-\mathbf L\|<\varepsilon
  $$
- Significado de $\varepsilon$.
- Significado de $\delta$.
- Búsqueda de $\delta(\varepsilon)$.
- Casos con $\varepsilon$ numérico.
- Casos con $\varepsilon$ arbitrario.
- Acotación de componentes.
- Uso de $|\sin t|\le |t|$.
- Uso de $1-\cos t\le \frac{t^2}{2}$.
- Uso de cotas logarítmicas.
- Restricciones auxiliares.
- Elección de $\delta=\min\{\delta_1,\delta_2,\ldots\}$.
- Interpretación de $\delta$ como tolerancia.
