# 03.3 — Intervalo del parámetro

El intervalo de $t$ determina qué parte de la curva se recorre.

## Casos frecuentes

- Toda una recta: $-\infty<t<\infty$.
- Segmento entre dos puntos: normalmente $0\le t\le1$.
- Circunferencia completa: $0\le t\le2\pi$.
- Solo un arco o tramo: se restringe el intervalo según los puntos deseados.

El mismo par de ecuaciones puede representar la curva completa o solo una parte. La diferencia está en el dominio asignado al parámetro.
