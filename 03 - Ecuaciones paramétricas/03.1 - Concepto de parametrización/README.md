# 03.1 — Concepto de parametrización

Parametrizar una curva significa expresar cada coordenada como función de una variable auxiliar llamada **parámetro**, normalmente $t$:

$$x=f(t), \qquad y=g(t)$$

También puede escribirse en forma vectorial:

$$\vec r(t)=\langle f(t),g(t)\rangle$$

Por ejemplo:

$$x=6-3t, \qquad y=t-1$$

equivale a:

$$\vec r(t)=\langle 6-3t,t-1\rangle$$

Cuando $t$ cambia, el punto $(x(t),y(t))$ se mueve y va trazando la curva.

## Idea esencial

La ecuación cartesiana describe qué puntos pertenecen a la curva. La parametrización añade información sobre **cómo se recorre**: inicio, final, dirección y rapidez.
